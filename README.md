# 批量图片剪裁工具 batch-image-cropper

纯前端单文件的批量图片剪裁工具:一次导入多张图,支持按**比例 / 像素 / 自由**剪裁,每张图可**独立配置**剪裁框后批量导出。图片全程在浏览器本地处理,**不上传服务器**。

## ✨ 特性
- 🖼️ 批量导入,逐张独立设置剪裁区域
- 📐 三种模式:固定比例 / 固定像素 / 自由剪裁
- 🔒 纯本地处理,图片不上传,隐私安全
- 📦 单文件 `index.html`,双击即用,零依赖零安装

## 🚀 使用
直接双击打开 `index.html`,或起个静态服务器:
```bash
npx serve .
```

## 🧩 技术
纯前端(HTML + Canvas + JavaScript),单文件实现。
